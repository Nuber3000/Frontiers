# Сконе

Сконе — земля викингов, которой правят несколько ярлов и великий конунг.
Лидер фракции — **Конунг Ульфрик Синезубый**.

Фракция сохранена для следующего этапа. Сейчас она недоступна для выбора:
способность фракции, варианты способностей Ульфрика, полный состав колоды и
правила её комплектования ещё не определены.

Для Сконе сохранены следующие карты вместе с эффектами и иллюстрациями:

| Карта | Ключ |
| --- | --- |
| Бешеный ратник | `berserker` |
| Лесной берсерк | `young_berserker` |
| Великий медведь — вторая форма ратника | `war_bear` |
| Лесной медведь — вторая форма лесного берсерка | `young_bear` |
| Мухомор | `mushroom` |
| Лесной стрелок | `ranger` |
| Альбан, лесной мудрец | `druid` |
| Шторм | `storm` |

В каталоге они помечены `faction: skone`, `available: false`. Редактор Бургундии
не показывает их, а сервер отклоняет колоды с этими картами. Готовая колода
«Лесная дружина» удалена. Она смешивала карты разных фракций и не переносится
автоматически в Сконе.
