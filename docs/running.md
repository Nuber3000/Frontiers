# Локальный запуск и проверка Frontiers

Требуется Python 3.12 или новее. Браузерный интерфейс раздаёт тот же сервер, что
обрабатывает игру: отдельная сборка JavaScript не нужна.

## Windows / PowerShell

В корне проекта создайте окружение, если его ещё нет:

```powershell
py -3 -m venv .venv
```

Установите приложение и зависимости автоматических проверок, затем запустите:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\.venv\Scripts\python.exe -m frontiers
```

Откройте http://127.0.0.1:8000. Сервер останавливается сочетанием Ctrl+C.

## Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
.venv/bin/python -m frontiers
```

## Матч на одном компьютере

1. Откройте сайт, введите имя и создайте комнату.
2. Скопируйте приглашение.
3. Откройте приглашение в другом браузере или приватном окне. Введите второе имя
   и войдите в комнату. Обычные вкладки одного браузерного профиля разделяют сессию
   и потому принадлежат одному игроку.
4. Выберите готовую колоду или измените её состав, выберите вариант Франциска.
5. Оба игрока нажимают «Готов к матчу».
6. Замените до двух карт или оставьте руку. Затем играйте карты, используйте
   лидера и пасуйте. Карта выбирается нажатием; допустимые ряды и цели подсвечены.
7. После матча оба игрока могут подтвердить готовность к реваншу.

## Два компьютера в одной локальной сети

Запустите сервер с привязкой к сетевым интерфейсам:

```powershell
.\.venv\Scripts\python.exe -m frontiers --host 0.0.0.0 --port 8000
```

Откройте сайт по локальному IP компьютера с сервером, например
`http://192.168.1.10:8000`, и копируйте приглашение с этой страницы. Ссылка с
`127.0.0.1` работает только на компьютере, где её открывают. Доступ к порту
настраивается в межсетевом экране ОС. Публикацию в интернете, HTTPS и контейнеры
разбираем на следующем DevOps-этапе.

## Тесты правил и API

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверки покрывают ходы, все реализованные эффекты, завершение раундов, скрытую
информацию, комнаты, сессии, WebSocket, реванш и конкурентные команды. В набор
также входит симуляция 100 полных матчей на разных начальных состояниях.

## Браузерная проверка

Кнопка с четырьмя уголками включает и выключает полноэкранный режим. Во время
матча она находится рядом с надписью Frontiers. Для выхода также можно нажать Esc.
Поле подстраивается под новый размер окна, матч и выбранные карты сохраняются.
Если браузер не поддерживает Fullscreen API, кнопка не отображается.

Дополнительная зависимость нужна только для этой проверки:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[test,browser]"
.\.venv\Scripts\python.exe tests/browser_smoke.py --browser msedge
```

Вместо Edge можно выбрать установленный Chrome через `--browser chrome`.
Для отдельного Chromium, в том числе на Linux:

```bash
.venv/bin/python -m playwright install chromium
.venv/bin/python tests/browser_smoke.py --browser chromium
```

Проверка сама запускает временный сервер, открывает два независимых браузерных
контекста, играет матч, проверяет перезагрузку страницы, реванш, пас и мобильную
ширину, затем останавливает сервер. Проверка размеров также подтверждает, что
поле, рука и основные кнопки помещаются в высоту окна без вертикального скролла
на нескольких разрешениях, включая 1366×768 и 390×844. Снимки экрана и журнал временного сервера
сохраняются в `artifacts/browser/`; каталог исключён из Git.

Также проверяются раздельные списки коллекции и колоды, добавление/удаление карты,
фильтр боевой линии, открытие хроники и сброса. На компьютере оба игровых экрана
помещаются в окно; длинные коллекции прокручиваются внутри своих колонок.
На телефоне подготовка колоды использует вертикальную страницу, а матч сохраняет
размещение без вертикальной прокрутки. Изображения включены в Python-пакет;
внешний CDN и сборщик фронтенда не требуются.

## Настройки приложения

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| `FRONTIERS_HOST` | `127.0.0.1` | Сетевой адрес; также есть аргумент `--host` |
| `FRONTIERS_PORT` | `8000` | Порт; также есть аргумент `--port` |
| `FRONTIERS_MAX_ROOMS` | `128` | Максимум комнат в одном процессе |
| `FRONTIERS_SECURE_COOKIES` | `0` | Значение `1` разрешает передачу сессионной cookie только через HTTPS |

Настройки читаются из окружения процесса. Сам по себе файл `.env` не загружается.
Для разработки есть `--reload`: изменение кода перезапускает сервер и удаляет
текущие матчи из памяти.

## Ограничения первой версии

- Один процесс сервера. Несколько Uvicorn workers или реплик пока не поддержаны,
  поскольку комнаты хранятся в памяти.
- Перезапуск сервера удаляет комнаты и матчи. Перезагрузка страницы сохраняет
  место, если сервер продолжает работать и сессия браузера не очищена.
- Пустые и завершённые комнаты удаляются после часа бездействия; активные матчи —
  после суток. Подключённый интерфейс поддерживает сессию heartbeat-сообщениями.
- Три доступные фракции: Бургундия, Широн и Сконе; у каждой готовая колода
  и пять вариантов лидера. Внешние аккаунты, постоянное хранение и рейтинг — дальнейшее развитие.

Отдельная проверка Сконе в двух сессиях проверяет валькнут, Командный рог,
воскрешение в третьем раунде и очередь лекарей обеих сторон:

```powershell
.\.venv\Scripts\python.exe -X utf8 tests/browser_skone.py --browser msedge
```
