# Исходные звуки

Здесь сохранены MP3-записи до перевода в Opus и присланные Ogg-записи.
Не перекодируйте игровые Ogg повторно: для нового экспорта используйте эти
исходники. Присланные Ogg копируются в игру без изменений и потери качества.

Игровые записи находятся в `src/frontiers/static/audio/`. Настройки сжатия
сохранены в `tools/audio-settings.json`: Opus, VBR, 96 кбит/с; для огня —
32 кбит/с, для поражения — 24 кбит/с с ограниченным VBR, чтобы не увеличивать
уже компактные записи.

Повторная подготовка: `python tools/prepare_audio.py --ffmpeg <путь-к-ffmpeg>`.
Сжатие с потерями; громкость и затухание задаются игрой при воспроизведении.
Эта папка не входит в Docker-контекст и установочный пакет.
