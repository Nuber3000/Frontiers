# Исходные иллюстрации

PNG-оригиналы сохранены для будущего редактирования без дополнительных потерь.
Игра использует WebP в `src/frontiers/static/`. Эту папку не нужно копировать
на сервер: она исключена из Docker-контекста и пакета приложения.

Повторная подготовка изображений: `python tools/prepare_art.py` из корня проекта
в окружении с Pillow. Не конвертируйте уже сжатый WebP повторно.
