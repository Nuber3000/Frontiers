# Frontiers

Учебный open-source проект: браузерная карточная игра для двух игроков по сети,
с механиками Гвинта из The Witcher 3 и собственными фракциями и картами.
Разработка начинается с одной собственной фракции.

## Цель первой версии

- Два игрока могут сыграть матч друг с другом по приглашению.
- Сервер хранит состояние матча и проверяет допустимость ходов.
- У каждой фракции собственные карты и игровые особенности.
- Игра запускается локально, а позднее получает инструкцию для самостоятельного
  развёртывания на Linux-сервере.

В первой версии не планируются боты, аккаунты, рейтинг и история матчей.

## Сеттинг и игровые материалы

Проект использует собственные фракции, персонажей, названия, карточные тексты и
оформление. Цель по механикам — воспроизвести правила Гвинта из The Witcher 3;
решения по игровым правилам будем сверять с официальным руководством и самой игрой.

Официальные правила CD PROJEKT RED для фанатского контента отдельно ограничивают
создание игр, основанных на их играх. Это политика компании, а не заключение о
правовом статусе игровых механик. Перед публичным релизом стоит проверить условия
публикации и распространения проекта.

## Учебный план

1. Зафиксировать правила и границы первой версии.
2. Создать сервер на Python и FastAPI.
3. Реализовать правила игры отдельно от сетевого взаимодействия.
4. Добавить комнаты и передачу ходов между игроками.
5. Сделать простой браузерный интерфейс.
6. Подготовить локальный запуск через Docker Compose.
7. Добавить автоматические проверки и инструкцию для Linux-сервера.

Проект будет развиваться небольшими шагами. Перед добавлением новой части мы
разбираем, зачем она нужна и как работает.

## Статус

Начальный каркас проекта. Игровые правила и сервер ещё не реализованы.
