# Frontiers

Карточная дуэль для двух друзей в браузере. Доступны **Королевство Бургундия**
с Франциском II Мудрым и **Империя Широн** с Императором Альбрехтом Тиролем.
Комнаты по приглашению, редактор колоды, готовые «Королевская гвардия» и
«Императорский легион», по пять вариантов способности каждого лидера.

## Запуск в Windows

Из корня проекта, где уже создано окружение `.venv`:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\.venv\Scripts\python.exe -m frontiers
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000), создайте комнату и отправьте
приглашение другу. Для двух игроков на одном компьютере используйте разные
браузеры или приватное окно.

[Подробная инструкция](docs/running.md) описывает Linux, локальную сеть, настройки
приложения и проверки. Правила в интерфейсе доступны по кнопке «Как играть».

## Что работает

- Комната для двух игроков, выбор фракции, собственной колоды и способности лидера.
- Замена начальной руки, очередность ходов, пас, раунды, ничья, сдача и реванш.
- Герои, шпионы, Лекари и их цепочки, Призыв, Сплочённость, Прилив сил,
  Знаменосец и гибкое размещение.
- Ливень, Туман, Мороз, Шторм, Ясное небо, Казнь, Штандарт и Чучело.
- Призываемый отряд Наследия и все пять способностей Франциска.
- Скрытая рука соперника, серверная проверка действий и восстановление после
  перезагрузки страницы или временного сетевого разрыва.
- Интерфейс для компьютера и телефона, журнал действий и просмотр сброса.
- Крупный показ сыгранной карты соперника с перемещением на поле; Казнь сгорает
  перед уничтожением целей. Разведданные показываются отдельным широким окном.
- Экран колоды с коллекцией слева, лидером в центре и выбранными картами справа;
  деревянный игровой стол с шестью рядами и рукой внизу без прокрутки страницы.

У каждой из 74 уникальных карт и десяти вариантов лидера своя иллюстрация.
Восемь определений карт, включая медвежьи формы и Шторм, сохранены в резерве для будущей
[Сконе](docs/skone.md). Они недоступны в колодах Бургундии.
Изображения хранятся в проекте и загружаются локально. [Ресурсы оформления и промпты](docs/artwork.md).

Игровые механики ориентированы на мини-игру из The Witcher 3 с Blood and Wine.
Персонажи, имена, карточные описания и оформление Frontiers собственные.
[Правила и решения первой версии](docs/rules.md) фиксируют детали реализации.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Набор включает тесты движка и API, проверки конкурентных ходов и симуляцию
100 полных матчей. Отдельная [браузерная проверка](docs/running.md#браузерная-проверка)
играет в двух независимых сессиях и проверяет возврат в матч, реванш и мобильную ширину.

## Текущая граница

Игровая версия готова к этапу контейнеризации. Docker, Compose, CI/CD и серверный
деплой будут разбираться вместе с владельцем проекта.

Комнаты хранятся в памяти **одного процесса**. Перезапуск сервера удаляет матчи;
несколько workers/реплик требуют другого хранилища. Аккаунтов, рейтинга и базы
данных в первой версии нет.

Лицензия исходного кода ещё не выбрана.
